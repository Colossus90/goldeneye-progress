# GoldenEye: Rogue Agent decompilation — progress

The progress page of the GoldenEye: Rogue Agent (GameCube, GOYE69) decompilation:
**https://colossus90.github.io/goldeneye-progress/**

This repository holds only the published page: `index.html` and `data.json`. The data lists names,
addresses, sizes, match scores and statuses of the functions, and the titles of the project's issues;
it contains no game code or data. It is generated from the decompilation's objdiff report and
refreshed at the end of every work round. The page's **refresh data** button loads the newest
published `data.json`.
