What the statuses mean
  • Matching: 100 %
  • Equivalent: behaves like the original, not byte-identical
  • Not matching: had a pass, below 100 % and not equivalent
  • Not started: no pass yet

Inline copies are functions the compiler emitted into more than one file (inline functions, templates, weak symbols); the linker keeps one copy. They are listed under the file that owns the kept copy and folded into an “inline copies” group.

Original files are the source files the game's large “unity” files were built from. Most are named by symbols of related games built from the same code, or by the game's own file-name strings. Where nothing names a function's file it is guessed: such functions are marked “file guessed”, and a file that no symbol names at all is marked “name guessed”.

Only names, addresses, sizes, scores and statuses are published here, never game data. The data is generated from the objdiff report of the decompilation by tools/progress_site.py and refreshed at the end of every work round. How this page is built
